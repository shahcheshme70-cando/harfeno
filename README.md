# محتوای حرف نو

فهرست جست‌وجوپذیر محتوای نمایشگاه حرف نو، به تفکیک بخش‌ها، سالن‌ها و ایستگاه‌ها.

## افزودن یا ویرایش محتوا

1. فایل `.md` را در پوشهٔ سالنش بگذارید: `content/salon-3/` ، `content/salon-16/` …
   - `salon-0` = ورودی و اسناد پایه
   - `salon-b` = بعثت زنانه
2. بالای فایل این سرآیند را بنویسید (همه اختیاری‌اند):

```
---
title: روایت — امیدبانی
station: 4
type: روایت
summary: یک جملهٔ کوتاه دربارهٔ محتوا
---
```

انواع: متن تابلو · روایت · سازهٔ هرمی · جزوه · فهرست · سند · سناریو · بریف · اطلاع‌نگاشت · آزمون

3. Commit کنید. اکشن «ساخت فهرست محتوا» فایل `content.json` را دوباره می‌سازد و صفحه به‌روز می‌شود.

نام سالن‌ها و ایستگاه‌ها در `halls.json` است.

## اجرای محلی

```
python3 build.py
python3 -m http.server
```
