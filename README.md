# محتوای حرف نو

فهرست جست‌وجوپذیر محتوای نمایشگاه حرف نو، به تفکیک بخش‌ها، سالن‌ها و ایستگاه‌ها.

## افزودن یا ویرایش محتوا

1. فایل‌ها را در پوشهٔ ایستگاهش بگذارید: `content/salon-03/istgah-02/` (در هر پوشه یک README نام ایستگاه را نشان می‌دهد)
   - `salon-00` = ورودی و اسناد پایه
   - `salon-b` = بعثت زنانه
2. بالای فایل این سرآیند را بنویسید (همه اختیاری‌اند):

```
---
title: روایت — امیدبانی
station: 4
type: روایت
summary: یک جملهٔ کوتاه دربارهٔ محتوا
---
```

انواع: متن تابلو · روایت · سازهٔ هرمی · جزوه · فهرست · سند · سناریو · بریف · اطلاع‌نگاشت · آزمون

3. Commit کنید. اکشن «ساخت فهرست محتوا» فایل `content.json` را دوباره می‌سازد و صفحه به‌روز می‌شود.

نام سالن‌ها و ایستگاه‌ها در `halls.json` است.

## اجرای محلی

```
python3 build.py
python3 -m http.server
```

## نکته‌های دیپلوی روی سرور

- کل مخزن را در مسیر سایت (مثلاً `mohtava/`) قرار دهید؛ ساخت یا نصبی لازم نیست.
- برای رسیدن محتوای تازه، `git pull` را خودکار کنید (cron هر چند دقیقه، یا webhook گیت‌هاب).
- کش پیشنهادی:
  - `index.html` و `content.json`: بدون کش طولانی (`Cache-Control: no-cache`)
  - `assets/` و `generated/`: کش طولانی (مثلاً ۳۰ روز)
- نوع فایل‌ها باید درست تعریف شده باشد: `.webp` ← `image/webp`، `.woff` ← `font/woff`، `.docx` ← `application/vnd.openxmlformats-officedocument.wordprocessingml.document`
- فشرده‌سازی gzip/brotli را برای `.html` ، `.json` و `.js` روشن کنید (حجم `content.json` حدوداً یک‌چهارم می‌شود).
- سایت به هیچ سرویس خارجی (CDN) وابسته نیست.
